# Architecture Système — APISTOCK

APISTOCK est conçu comme une plateforme modulaire permettant de gérer les stocks, automatiser les opérations et supporter des extensions innovantes.

## Composants principaux

- **Backend API (Node.js + Express + MongoDB)**  
  Fournit les endpoints REST, la logique métier et la sécurité.

- **Frontend (Next.js / React)**  
  Interface moderne pour la gestion des stocks, tableaux de bord et reporting.

- **Application Desktop (Electron)**  
  Version hors-ligne pour entrepôts, avec synchronisation automatique.

- **DevOps (GitLab CI/CD)**  
  Pipeline complète : lint, tests, qualité, sécurité, build, déploiement.
