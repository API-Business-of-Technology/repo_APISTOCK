# Référence API — APISTOCK

Documentation des endpoints principaux.

## Authentification

- JWT  
- Rôles (admin, opérateur, lecteur)

## Produits

- `GET /products`
- `POST /products`
- `PUT /products/:id`
- `DELETE /products/:id`

## Entrées de stock

- `POST /stock/in`

## Sorties de stock

- `POST /stock/out`

## Mouvements

- `GET /movements`
