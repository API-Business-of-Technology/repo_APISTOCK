# Architecture Desktop — APISTOCK

L’application desktop est développée avec **Electron**.

## Objectifs

- Fonctionner hors-ligne  
- Synchroniser automatiquement les données  
- Offrir une interface simple pour les entrepôts

## Modules

- Gestion locale des données  
- Synchronisation API  
- Interface optimisée pour scanners et lecteurs de codes-barres
